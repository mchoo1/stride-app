No separate outlet-level nutrition search was needed this session: per the prior two sessions' notes, the dine-in/bubble-tea candidates in the priority-1/2 categories (Each-A-Cup, Kenangan Coffee, Ichiban Boshi, Itacho Sushi, Seoul Garden, Märché Mövenpick) have already been confirmed to publish no official SG nutrition data, and would require T3/T5 admin-approval items. Kopitiam, as a food-court/coffeeshop operator, sells the standard set of hawker + kopitiam-drink dishes already covered with **HPB-verified** macros in `SG_MACRO_FOODS`. Per the Phase 4 waterfall rule ("If the macroDbRef key already exists in sgFoodDb.ts, no approval needed"), a full 12-item menu was built with zero admin review.

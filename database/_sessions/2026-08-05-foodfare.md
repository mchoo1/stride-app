## Why this outlet

Checked `_index.json`, `sgFoodDb.ts`, `database/restaurants/`, and `database/grab-and-go/` first — no existing `foodfare` entry or id collision anywhere.

`SG_UNRESEARCHED_CHAINS` in `sgFoodDb.ts` flags Foodfare as `priority: 'high'` (same tier as Kopitiam/Koufu/Banquet) with the explicit note "Use HPB nutrient data for generic hawker dishes." Koufu (same operator category) was completed on 2026-08-03 using this exact approach with zero admin approval required.

Before settling on Foodfare, I checked several bubble-tea and dine-in candidates for official SG nutrition sources per the priority-1/2 guidance:
- **Each-A-Cup** (bubble tea) — official site (each-a-cup.com) has a menu/products page but no calorie or nutrition data anywhere.
- **Kenangan Coffee** (Kopi Kenangan, fast-growing Indonesian coffee chain, SG outlets at Raffles City/Changi T2) — official site (kenangancoffee.sg) lists signature drinks but publishes no nutrition panel. Only nutrition data findable was for Indonesian retail bottled RTD products (different product line, not the cafe menu), which isn't a valid stand-in.
- **Ichiban Boshi, Itacho Sushi, Seoul Garden, Marché Mövenpick** — re-confirmed (per prior Koufu session notes) that none publish an official SG nutrition PDF.

All of the above would require T3 (ai_estimate) or T5 guesses — every item flagged for admin approval. Foodfare, as a food-court operator, sells the standard set of hawker dishes already covered with **HPB-verified** macros in `SG_MACRO_FOODS`. Per the Phase 4 waterfall rule ("If the macroDbRef key already exists in sgFoodDb.ts, no approval needed"), an entire 12-item menu can be built with zero admin review — the same reasoning that made Koufu the right pick last session.

## Menu construction

Selected 12 different hawker dishes than the Koufu session (no near-duplicates across the two outlets) to maximize `SG_MACRO_FOODS` coverage: noodles, soup, rice, Western, and drinks. All macros, prices, and category data come directly from existing `SG_MACRO_FOODS` entries — no numbers invented.

## Why this outlet

Checked `_index.json`, `sgFoodDb.ts` (both `SG_RESTAURANTS` and `SG_MACRO_FOODS`), `database/restaurants/`, and `database/grab-and-go/` first — no existing `banquet` id or name collision anywhere.

`SG_UNRESEARCHED_CHAINS` in `sgFoodDb.ts` flags Banquet as `priority: 'medium'` with the note "Use HPB nutrient data for generic hawker dishes" — the same category as Kopitiam/Koufu/Foodfare, all three of which were completed in prior sessions (2026-08-03 → 2026-08-06) using this exact HPB-macroDbRef approach. The Kopitiam session (2026-08-06) explicitly flagged Banquet as "unclaimed for a future session," so this session picks it up.

Before committing, I re-checked several dine-in/beverage candidates (Swensen's, Fish & Co, Pepper Lunch, Kenny Rogers Roasters, Itacho Sushi, Ichiban Boshi, Tiger Sugar, The Alley, Stuff'd Roti John, Seoul Garden) for an official SG nutrition PDF or page — consistent with the findings already logged in the Koufu/Foodfare session reports, none publish one. All of those would put every item at T3 (ai_estimate) or T5, flagged for admin approval. Banquet, as a food-court operator, sells the standard set of hawker/coffeeshop dishes already covered with **HPB-verified** macros in `SG_MACRO_FOODS`. Per the Phase 4 waterfall rule ("If the macroDbRef key already exists in sgFoodDb.ts, no approval needed"), a full 12-item menu was built with zero admin review — same reasoning as the three prior food-court sessions.

**Outlet note:** Banquet was Singapore's first all-halal food court (opened at Jurong Point in 1999, per multiple SG halal-dining sources including Zabihah's halal restaurant directory and Yelp's Halal tag on the current VivoCity outlet, #B2-39, confirmed still operating as of April 2026). Because halal certification is the outlet's core, publicly documented identity — not an inferred assumption — `dietTags: ['halal']` is applied at the outlet level, unlike the Koufu/Foodfare/Kopitiam entries which left outlet-level dietTags empty for lack of confirmation. No active official Banquet website was found (the chain downsized significantly after reported financial difficulties around 2013), so `nutritionUrl` is omitted rather than pointed at a third-party listing.

## Menu construction

Selected 12 hawker/coffeeshop dishes not used by the Koufu, Foodfare, or Kopitiam sessions (no near-duplicates across all four outlets) to maximize `SG_MACRO_FOODS` coverage: noodles, rice, snacks, a soup/curry side, a dessert, and two kopitiam-style drinks. All macros, prices, and category data come directly from existing `SG_MACRO_FOODS` entries — no numbers invented.
